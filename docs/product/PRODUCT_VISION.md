# Product Vision

Status: Living document. Temporary product name: VibeCAD.

VibeCAD will be the easiest professional CAD application to use. A new user will state a need in plain language. The application will make a real, editable, parametric model. It will inspect, plan, act, validate, and recover. It will show assumptions and important choices in simple language.

The default workflow is conversation first. The viewport, model navigator, properties, and revision history support that workflow. Expert tools remain available through progressive disclosure.

The product is local first. Standard FreeCAD documents remain usable. AI changes are attributable, inspectable, reversible, and transactional. macOS is the first launch platform. Shared product logic remains portable.

Success requires valid geometry, correct dimensions, preserved editability, safe recovery, reliable export, and successful follow-up edits. Fluent text alone is not success.
